    Data Sources

    This website uses the following public data services:

    • OpenFreeMap Dark Basemap: Free tile service based on OpenStreetMap.
    • Satellite & Imagery: Esri World Imagery & USDA NAIP Imagery.
    • Parcel Layers & Data: IDWR Reference Parcels & County ArcGIS endpoints.
    • Tax & Assessment Portals: Public Access Now & County Assessor/Treasurer records.

    Under Idaho Code 74-120, owner names may be withheld on public layers. When names are unlisted, the situs address is provided as fallback context.
